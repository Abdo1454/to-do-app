# 📝 Todo App

A responsive and interactive Todo Application built using **HTML, CSS, and JavaScript**.  
This project focuses on improving DOM manipulation, state management, and localStorage usage.

---

## 🌐 Live Demo

 https://abdo1454.github.io/to-do-app/

---

##  Features

- ➕ Add new tasks  
- ❌ Delete tasks  
- ✅ Mark tasks as completed  
- 🔍 Filter tasks (All / Active / Completed)  
- 🧹 Clear all tasks  
- 🌙 Light / Dark mode toggle  
- 💾 Persistent data using localStorage  
- 📱 Fully responsive design  
- ⚡ Real-time UI updates without refresh  

---

##  Built With

- HTML5  
- CSS3  
- JavaScript (ES6)  
- LocalStorage API
